# Использование AI

Код, тесты и документация созданы с помощью AI по заданиям из txt и макетам Figma. Автоматическая генерация не заменяет review. Реально выполненные проверки перечислены в корневом STATUS.md. Ошибки, обнаруженные E2E: ввод до завершения hydration; неправильное сохранение JSONB. Исправления проверены повторным E2E.

Публикация Render/Neon выполнена через браузер пользователя после его входа и разрешения передать DATABASE_URL в окружение сервиса. Внешняя сеть выявила ранний app:mounted: trace показал GET /login? без API POST. Исправлены готовность страницы и disabled-состояние auth-форм, добавлен тест с задержанным JavaScript. Все 11 браузерных сценариев прошли на локальной production-сборке, в CI и на публичном demo. Секрет базы не сохранялся в Git или документацию.
