# Доступность

Проверка production Docker в Windows 11, Microsoft Edge, 16 ноября 2026.

`node tests/accessibility.mjs` проверяет публичные страницы и четыре роли: axe WCAG 2 A/AA, WCAG 2.1 AA на 1280 px, отсутствие горизонтального overflow на 360/768/1280 px. Включены архив администратора и закрытая заявка клиента. Фактические маршруты и результаты — [accessibility.json](audit/accessibility.json). Контрольные изображения — [screenshots](screenshots); полный набор генерируется локально и не хранится в Git.

## NVDA

Выполнена отдельная проверка с реально запущенным NVDA 2026.3.1, portable, без дополнений. Проверялись форма создания заявки администратора и диалог удаления категории. Удаление не подтверждалось; тестовые данные не менялись. Ниже — фрагменты речевого вывода NVDA, а не прогноз по accessibility tree:

| Действие | Речевой вывод |
| --- | --- |
| Фокус темы | «Тема», «редактор», «обязательно», «пусто» |
| Tab к описанию | «Описание», «редактор», «многострочный», «пусто» |
| Выбор категории | «Категория», «комбинированный список», «Без категории», «свёрнуто» |
| Выбор приоритета | «Приоритет», «комбинированный список», «Обычный», «свёрнуто» |
| Отправка пустой формы | «Заполните это поле», «уведомление»; фокус возвращается на тему |
| Открытие подтверждения | «Удалить запись?», «диалог», «IT-поддержка» |
| Tab внутри диалога | «Отмена», «кнопка» |
| Escape | Диалог закрывается; «Удалить IT-поддержка», «кнопка» |

После проверки NVDA остановлен. Полный диагностический speech log не публикуется: он может содержать названия посторонних окон.

Keyboard E2E дополнительно проверяет вход, мобильное меню со стрелками/Escape, возврат фокуса из диалога и выбор оценки нативными radio через Space/ArrowRight. Это ограниченная проверка конкретных сценариев; полноценный пользовательский аудит со всеми экранными дикторами и сертификация WCAG не проводились.
