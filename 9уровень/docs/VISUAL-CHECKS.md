# Сверка с Figma

Источник: [предоставленный макет](https://www.figma.com/design/ZBsMj7Zz9kthkAsENAPE0x/?node-id=0-1). Получены детальные контексты экранов обзора Operator `1:38199`, Client `1:38270`, Agent `1:38244`, Admin `1:38296`, списка администратора `1:37133` и оценки `1:36680`, `1:36753`.

В финальном уровне приведены к этим кадрам цвета, фон, Montserrat, размеры заголовков, шапка, контейнер 1152 px, карточки, кнопки и таблицы. Обзор зависит от роли: KPI только у оператора, архив у администратора. Иконки приоритетов, статусов и уведомлений получены из Figma; оригинальные SVG находятся в `public/design`.

`node tests/visual-contract.mjs` проверяет четыре экрана обзора при 1280×900. Для оператора: шапка 80 px, заголовок x=64/y=104, карточки y=208 и 276×154, раздел y=386, кнопка y=438, таблица y=502, заголовок таблицы 48 px, строки 54 px. Для остальных ролей проверяются общая геометрия и отсутствие лишних KPI. [Измерения](audit/visual.json), [снимки](screenshots).

Это проверка выбранных размеров, не сравнение каждого пикселя. Дальнейшее получение контекстов было ограничено лимитом Figma MCP. Все состояния всех экранов не сверены; полное pixel-perfect соответствие не подтверждено. Для новых подтверждений архива используются существующие доступные компоненты приложения.
