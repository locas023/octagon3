# Демо на 5 минут

1. Открыть FAQ, помощь и статью, показать поиск и прямую ссылку.
2. Войти client@workflow.demo / WorkflowDemo2026!, создать заявку.
3. Выйти, войти operator@workflow.demo, назначить Demo agent, перевести в «Назначена».
4. Войти agent@workflow.demo, перевести в работу, добавить комментарий; решение требует причины.
5. Войти admin@workflow.demo, открыть SLA и аналитику. Показать ограничения файла и уведомления.

Без публичного deploy demo URL локальный: http://127.0.0.1:3009. Видео не записано.
