# Демо на 5 минут

Публичный URL: https://octagon3-workflow.onrender.com. Демо-аккаунты используют пароль `WorkflowDemo2026!`. После простоя заранее открыть сайт и дождаться пробуждения Free-сервиса.

1. Открыть FAQ, помощь и статью, показать поиск и прямую ссылку.
2. Войти client@workflow.demo / WorkflowDemo2026!, создать заявку.
3. Выйти, войти operator@workflow.demo, назначить Demo agent, перевести в «Назначена».
4. Войти agent@workflow.demo, перевести в работу, добавить комментарий; решение требует причины.
5. Клиентом подтвердить решение и выбрать оценку 1–5; обновить страницу и показать сохранённую оценку.
6. Администратором архивировать закрытую заявку через подтверждение, найти её во вкладке «Архив», затем восстановить. Открыть SLA и аналитику.

Локальный Docker URL: http://127.0.0.1:3019. [Записанное краткое видео](demo/workflow-demo.webm) показывает публичные страницы, создание, назначение, комментарий и административные экраны. Сценарий выше рассчитан на живой показ на 5 минут; видео — короткий обзор. Перезапись: `node tests/record-demo.mjs`, требуются Playwright Edge и ffmpeg.
