Проверены SSR h1, canonical, 404 отсутствующей статьи, отсутствие ошибок hydration/JS и горизонтального скролла на 360/768/1280. FAQ screenshot: screenshots/faq.png.

Эти величины не являются LCP/INP/CLS и не заменяют Lighthouse. Сопоставимого измерения до/после оптимизации нет — соответствующий пункт задания остаётся открытым. Бюджет HTML <100 КБ соблюдён; performance budget Web Vitals пока не подтверждён.

Разделение кода по маршрутам оставляет административные страницы вне начального чанка публичных страниц. Статьи используют SSR и локальный контент. Динамические private endpoints не кэшируются. Не добавлен общий SWR для авторизованных страниц, чтобы не смешивать данные разных пользователей.
