# Performance

Lighthouse 13.6, Edge headless, default mobile simulated throttling, production Docker на localhost. Один диагностический прогон на страницу до и после; скорость внешней сети и машины влияет на результат. Сырые JSON и время замеров: `performance/before` и `performance/after`.

| Страница | Performance до → после | LCP до → после, мс | CLS после | TBT после, мс | Transfer до → после, байт |
| --- | --- | --- | --- | --- | --- |
| / | 96 → 100 | 2302 → 919 | 0 | 5,5 | 354940 → 363842 |
| /faq | 97 → 100 | 2157 → 761 | 0 | 2 | 351233 → 360850 |
| /help | 95 → 99 | 2316 → 777 | 0 | 100,7 | 353106 → 362726 |

Бюджет: LCP <2500 мс, CLS <0,1, SSR HTML <100 КБ, отсутствие overflow на 360/768/1280. В этих локальных проверках соблюдён. Нет полевых INP/CrUX данных; TBT не выдаём за INP и единичные прогоны не выдаём за статистический benchmark.

Изменения: Google Fonts заменены локальным variable Montserrat, убраны внешние stylesheet/preconnect; шрифт больше не блокируется внешней сетью. Передача немного выросла, зато LCP в данном окружении снизился. Сохраняем SSR содержимого и route splitting, не дублируем каталог статей в глобальном Pinia. Картинки интерфейса преимущественно SVG; перенос важного текста в изображения не нужен. Долгое кеширование применяется только к хешированным `_nuxt` assets, приватные API получают no-store.

Hydration: localStorage читается после mounted, состояние меню/плотности не меняет первый SSR HTML. `tests/public-check.mjs` проверяет исходный h1/canonical, 404, ошибки JS/hydration и три ширины. Последний HTML: примерно 12–18 КБ. Целевые страницы — /, /faq, /help, /articles, /articles/first-request.

Повторный замер из финальной папки: `TEST_URL` указывает на production сервер; `node tests/performance.mjs after`. На Linux указать `EDGE_PATH` к установленному Chrome/Edge. Повторный запуск перезапишет after; baseline сохраняется отдельно.

Уровни 6–8 используют те же публичные страницы и оптимизацию шрифтов. Приведённые числа измерены на финальном снимке 9, отдельными замерами каждого предыдущего снимка они не являются.
