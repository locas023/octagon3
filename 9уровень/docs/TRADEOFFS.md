# Компромиссы

- JSONB упрощает последовательные учебные уровни, но ограничивает декларативную целостность; см. ARCHITECTURE.md.
- Вложения хранятся в PostgreSQL: транзакционный лимит 5 файлов и простое резервирование, но рост базы. Для production нужно объектное хранилище и антивирусная проверка.
- Фильтрация заявок выполняется после загрузки доступной выборки в память. Для больших объёмов перенести предикаты в SQL и добавить индексы.
- Срок SLA задаётся при создании; изменение настроек не пересчитывает прошлые заявки. Аналитика «в пределах срока сейчас» не является историческим процентом соблюдения SLA.
- Уведомления SLA вычисляются при запросе, отдельного фонового планировщика нет.
- Демонстрационные аккаунты имеют общий опубликованный пароль. Для внешнего деплоя их нужно удалить/отключить и создать индивидуальные аккаунты.
- Docker и CI требуют запуска в соответствующем окружении; наличие файлов не подтверждает успешный запуск.
