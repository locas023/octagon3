# WorkFlow — учебные уровни

**[Открыть публичное демо](https://octagon3-workflow.onrender.com)** · [CI](https://github.com/locas023/octagon3/actions) · [Финальная версия и документация](9уровень/README.md)

Каждый уровень в отдельной папке. Для проверки выберите папку, выполните `npm.cmd install`, затем `npm.cmd run dev`. Уровни 4–9 требуют PostgreSQL, `.env` и предварительный `npm.cmd run db:setup`.

| Папка | Адрес | Основное изменение |
|---|---|---|
| 1уровень | 127.0.0.1:3000 | Интерфейс |
| 2уровень | 127.0.0.1:3002 | API и URL-фильтры |
| 3уровень | 127.0.0.1:3003 | Мутации, optimistic update, Undo |
| 4уровень | 127.0.0.1:3004 | PostgreSQL, сессии, роли |
| 5уровень | 127.0.0.1:3005 | Тесты и регрессии |
| 6уровень | 127.0.0.1:3006 | Публичные SSR-страницы |
| 7уровень | 127.0.0.1:3007 | Домены, сервисы, SQL, ADR |
| 8уровень | 127.0.0.1:3008 | SLA, вложения, уведомления |
| 9уровень | 127.0.0.1:3009 | Финальная версия, Docker на 3019 |

Демо для 4–9: `admin@workflow.demo`, `operator@workflow.demo`, `agent@workflow.demo`, `client@workflow.demo`; пароль `WorkflowDemo2026!`. Это искусственные учётные записи для локального обучения.

Подробное фактическое состояние, выполненные проверки и недоработки перечислены в [STATUS.md](STATUS.md). Финальные инструкции: [9уровень/README.md](9уровень/README.md). Локальные `.env` не входят в репозиторий.
