# Владение состоянием

- URL: поиск, фильтры, сортировка, пагинация. Восстанавливаются прямой ссылкой.
- Server state: заявки и справочники. Единственный источник — API; useFetch хранит клиентский кэш.
- App state: плотность списка в Pinia preferences, сохраняется в localStorage после hydration.
- Local state: текст комментария, pending, последнее отменяемое изменение внутри карточки.

Приоритет обновляется до ответа API; при 409/500 восстанавливается полный снимок. Параллельные изменения одной карточки блокируются до завершения запроса. Undo отправляет обратное изменение через API. Комментарий имеет ключ идемпотентности; повтор запроса с тем же ключом не создаёт дубль.
