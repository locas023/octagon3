# Performance

SSR включён для публичных страниц: содержательный HTML не зависит от client fetch. Контент импортируется локально, статьи разбиваются маршрутизатором на отдельные чанки. Настройки localStorage применяются только после mounted, чтобы первый рендер совпадал с SSR.

Бюджет: отсутствие горизонтального скролла 360–1280px; публичный HTML <100 КБ; LCP <2.5 с, CLS <0.1 в production. Последние две метрики требуют Lighthouse, их достижение пока не подтверждено.

Внешний Google Font остаётся компромиссом: в окружении проверки сеть может блокировать его, используется fallback. Реальные численные измерения до/после ещё предстоит получить; этот файл не является завершённым performance audit.
