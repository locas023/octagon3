# Регрессии

1. Быстрый двойной клик «Отправить»: два комментария. Причина — конкурентные запросы без ключа. Исправление: pending в UI, уникальный ключ в БД; integration/api.mjs отправляет два запроса одновременно и проверяет один комментарий.
2. Быстрый поиск A → B с медленным A: старый ответ заменяет новый. useFetch с отменой предыдущего запроса и query watcher владеет результатом. Требуется браузерный тест с задержкой ответа A.
3. Logout → прямой переход /requests: доступ к кэшу. Middleware проверяет серверную сессию каждый переход; logout очищает Nuxt cache. API integration проверяет 401, E2E проверяет переход на login.
4. Refresh сбрасывал фильтры и плотность. Фильтры читаются из URL; preferences загружаются после hydration. Требуется отдельная браузерная проверка.

E2E необходимо запускать с работающим сервером и seeded БД. Непройденные проверки не считаются выполненными.
