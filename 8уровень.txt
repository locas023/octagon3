Описание

На этом уровне WorkFlow получает новые требования бизнеса. Нужно расширить уже существующие домены и сохранить работоспособность старых сценариев. Каждое изменение должно проходить через данные, API, интерфейс и тесты.





Необходимо реализовать

добавить настраиваемый SLA для каждого приоритета через административный раздел;
добавить статус escalated с обязательной причиной эскалации;
добавить вложения с ограничением размера, количества и допустимых типов файлов;
добавить уведомления о назначении, эскалации и приближении SLA;
добавить административную аналитику по статусам, SLA и загрузке исполнителей;
обновить схему базы данных и seed/fixtures;
обновить API, UI и тесты во всех затронутых местах;
сохранить работу уже реализованных пользовательских сценариев.




Требования

расширение существующих доменов без дублирования функциональности;
воспроизводимое применение изменений схемы БД из чистого окружения;
покрытие новых бизнес-правил тестами;
сохранение работоспособности существующих E2E-сценариев;
настройка SLA для Critical, High, Normal и Low через admin-интерфейс.
